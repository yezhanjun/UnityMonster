# 怪物资源预览场景

打开 `Assets/Monsters/Jotunnslayer/MonsterPreview/MonsterPreview.unity`，按 Unity Play，在 Game 面板使用。
也可从菜单 `Jotunnslayer → 怪物预览 → 打开预览场景` 进入。
默认怪物：`draug_thrower_sur`。此场景不需要登录、联网或启动训练对局。

## 操作

- 左侧搜索框按模型 ID 筛选，点击列表切换模型。
- 右侧动作列表选择待机、移动、攻击等已提取动画；可暂停、循环、重播、0.1–2 倍速和拖动进度。
- 右侧特效列表点击播放，清除按钮停止并清理当前实例。尚无关联特效的模型会显示提示。
- 选择“随动作触发所选特效”可设置预览触发进度；这是可调预览组合，不是已复刻的战斗事件时间线。
- 圆形、90度扇形、直线框用于范围观察，可调半径/半宽、目标距离，地面网格为1米。
- 尸鬼 `skill_throw` 自动显示当前战斗实现中的投瓶爆炸半径1.5米。其余未关联参数的动作明确显示“自定义测量范围（非伤害判定）”；修改形状或半径后也回到该标记。
- 在中央画面右键拖动旋转、滚轮缩放；“镜头适配模型与范围”重新构图。
- 较小 Game 窗口可滚动右侧面板。高分辨率 Game 视图缩小显示时，可在 Unity Game 分辨率下拉中切换较低分辨率以增大界面文字。

## 当前范围与限制

当前目录有65个模型、440个动作关联条目、13个特效关联条目；条目数不等于去重资产数或已验收怪物数。目录从独立UnityMonster工程的怪物Resources文件夹生成，不改源模型/动画/材质。Draug优先使用Compact960动画。

此工具是资源与动作预览，不是联网战斗仿真。动画事件关闭；动画的碰撞、伤害、AI、投射物轨迹和音频不会自动执行。粒子可单独查看；死亡碎块在此作为静态特效资源展示，不把未接入的完整死亡链路包装成完成品。模型保留资源自身缩放，部分角色的战斗载体缩放、特殊材质设置或姿态修复仍需专门接入。

已验证默认尸鬼动作选择、进度拖动、爆炸特效生成和清理，以及至少3个其他模型的切换；没有逐一验证65个模型的全部动作与材质表现。

菜单“重建资源目录与场景”会更新本目录下的生成目录和场景；不要把手工布置保存在这份生成场景中，需自定义时另存场景。
