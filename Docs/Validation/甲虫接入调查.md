## 实际发现与解决的加载问题

直接加载单个包时，LoadAllAssets AnimationClip 没有取得目标动作；材质 Shader 显示 Hidden/InternalErrorShader，直接读取 mainTexture 也为空。这些现象不能证明模型没有贴图或动作。

使用原始序列化数据确认甲虫包有三个 CAB 依赖。随后在独立 Unity 批处理中，先加载 monoscripts、unitybuiltinassets、两个 duplicateassetisolation 包，再加载甲虫包。已通过 AnimatorOverrideController 的序列化覆盖槽取得真实片段，避免依赖只列出顶层资源的 LoadAllAssets 查询。

| 已解析动作 | 原片段时长 |
| --- | --- |
| beetle_minion_idle | 1.65 秒 |
| beetle_minion_fly | 2 秒 |
| beetle_veteran_attack | 0.6667 秒 |
| beetle_minion_stun | 3.3167 秒 |
| beetle_minion_summon | 1.65 秒 |
| beetle_minion_suicide | 0.08333 秒 |

通过 SerializedObject 读取材质 m_SavedProperties.m_TexEnvs，已确认 `_AlbedoMap` 为 beetle_minion_dm，另有 beetle_minion_nm、beetle_minion_em、beetle_minion_sm。导入时需要转换成 URP 材质，并将贴图像素持久化，避免引用原 AssetBundle 的归档流。
